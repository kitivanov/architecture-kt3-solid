# Демонстрация принципов SOLID на Python. КТ-3

## Описание

В проекте рализована имитация простой системы уведомлений,
разработанная на python для демонстрации применения принципов SOLID.

## Запуск

```bash
python main.py
```

## Результат работы

Программа выводит в консоль процесс отправки уведомлений через различные каналы и информацию о выполненных действиях.
